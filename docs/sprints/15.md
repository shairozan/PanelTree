# Sprint 15 [Post-MVP]: Book and chapter PDF export

## Outcome
Book and chapter PDF export.

## Queue
Sprint 15 of 19 · Post-MVP. Take the lowest-numbered open issue whose title starts with `Sprint`. Complete its acceptance criteria before closing it and advancing. Sprint numbers express delivery order, not fixed calendar dates. No agent delegation is required by this ticket.

## Prerequisites
- Sprint 09: MVP acceptance, portability, and contributor readiness
- Sprint 14: Web layer editing, review states, and scoped locks

## Scope
- Add a first-class PDF exporter to shared services and expose it through CLI, MCP and web UI.
- Support ordered books/chapters/page ranges, explicit physical trim dimensions, raster resolution and background handling.
- Produce immutable artifact outputs with export profiles/provenance; retain editable sources separately.
- Start with raster page assembly; clearly label basic printable PDF capabilities.

## Acceptance criteria
- [ ] Fixture PDF has correct page count, reading order, physical dimensions and effective image resolution.
- [ ] Render exported PDF pages back to images and visually compare them to expected pages.
- [ ] All three interfaces export the same revision and surface missing assets/stale approval diagnostics.
- [ ] Document limits; no PDF/X or press-ready claim without validated production profiles.
- [ ] Implementation, relevant tests, and usage documentation are in the repository; report verification and remaining limitations before closing.

## Ownership boundaries
internal/export/ PDF, output profile model, CLI/MCP/web integrations

## Out of scope
Printer-specific compliance, advanced color management, imposition.

## Architecture requirements
Go; command factories with invocation-local Viper and pointer-based pre-run initialization. CLI/MCP/web call shared application services. Composition drives renderer requests; stable project YAML remains backend-neutral. Preserve manual overrides and lock policy.
