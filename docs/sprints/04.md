# Sprint 04 [MVP]: SVG, lettering, and portable editable exports

## Outcome
SVG, lettering, and portable editable exports.

## Queue
Sprint 04 of 19 · MVP. Take the lowest-numbered open issue whose title starts with `Sprint`. Complete its acceptance criteria before closing it and advancing. Sprint numbers express delivery order, not fixed calendar dates. No agent delegation is required by this ticket.

## Prerequisites
- Sprint 03: PNG layers, transforms, masks, and first page render

## Scope
- Add a documented bounded SVG renderer and explicit-font text renderer with deterministic wrapping and measurement shared with layout.
- Reject unsupported SVG behavior and missing fonts; define basic Latin coverage and text overflow handling.
- Export PNG plus editable SVG groups, portable assets/masks and composition.json with IDs, hierarchy, transforms and provenance.
- Publish distinct build-addressed bundles so rebuilds do not overwrite externally edited output.

## Acceptance criteria
- [ ] Demo combines PNG character/environment, SVG prop, FX/mask and lettering.
- [ ] Real text measurement matches assigned layout widths; overflow and missing fonts have tests.
- [ ] Bundle opens with separate movable layers, preserves originals, and resolves assets after relocation.
- [ ] Visual comparison verifies PNG and editable output; documented limitations describe external-edit import and SVG coverage.
- [ ] Implementation, relevant tests, and usage documentation are in the repository; report verification and remaining limitations before closing.

## Ownership boundaries
internal/adapters/, internal/export/, measurement integration and fixtures

## Out of scope
PSD round-tripping, advanced shaping, PDF.

## Architecture requirements
Go; command factories with invocation-local Viper and pointer-based pre-run initialization. CLI/MCP/web call shared application services. Composition drives renderer requests; stable project YAML remains backend-neutral. Preserve manual overrides and lock policy.
